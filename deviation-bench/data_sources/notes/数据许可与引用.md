# 数据许可与引用

更新日期：2026-05-22

规范来源以 `deviation-bench/data_sources/下载清单与访问状态.md` 为准。这个文件只记录使用原则和写论文/代码时的引用边界。

## 使用原则

- 真实临床/访谈数据只能用于抽象语言模式、标注维度、rubric 校准和 aggregate analysis。
- 公开 benchmark prompt 应优先使用虚构、低风险、去身份化场景。
- 社区语料不能被当作临床诊断标签；只能标注文本信号，例如 reality-boundary language、self-referential pattern claim、persecutory-control claim。
- 合成数据、二次摘要数据、单轮问答数据和评估配置必须和真实访谈/临床对话分开描述。
- 受限数据不得绕过访问控制；申请前应写清研究目的、数据用途和不公开原始内容的承诺。
- 新增原始数据进 `downloaded/` 前，必须先补充来源、访问状态、license、local path、推荐用途和风险说明。

## 当前可引用来源类别

### 真实临床/访谈或治疗对话

- DAIS-C：CC BY-SA 4.0；真实 schizophrenia / control discourse。
- First-episode psychosis friendship interviews：CC BY 4.0；真实 first-episode psychosis qualitative interviews。
- AnnoMI：公开 motivational interviewing dialogues；不是 psychosis 数据，使用前复核源仓库 license。

### 合成或二次加工 mental-health 数据

- MentalChat16K：MIT；包含 synthetic counseling 和 interview-derived QA。
- MDD-5k：MIT；合成 diagnostic conversations，含一个 README 指出的 real patient case 示例，使用时避免复述敏感原文。
- CounselChat：OpenRAIL metadata；公开 counseling QA，不是连续临床对话。

### 社区语料

- Reddit Mental Health Dataset：ODC-PDDL；当前只下载 r/schizophrenia 子集。需同时遵守 Reddit 平台规则和研究伦理。
- RedditMentalhealth sample：公开 sample；完整数据需申请。

### 仅元数据 / 指针 / 方法参考

- PDCH metadata：完整数据 restricted，本地只有公开 metadata/code。
- EATD-Corpus pointer：本地只有 Git LFS 指针，未下载 543MB 原始包。
- Bloom / Weval：方法和配置参考，不是临床数据。

## 论文写法边界

推荐写法：

- “We use real clinical and counseling corpora only to derive abstract scenario patterns and annotation rubrics.”
- “Community posts are used as signals of reality-boundary language, not as clinical diagnoses.”
- “The released benchmark scenarios are fictionalized and de-identified.”

避免写法：

- “Reddit schizophrenia posts are delusion ground truth.”
- “The benchmark prompts are copied from patient transcripts.”
- “MDD-5k / MentalChat16K are real clinical psychosis dialogues.”
