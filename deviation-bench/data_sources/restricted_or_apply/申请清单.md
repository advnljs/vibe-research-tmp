# 受限 / 待申请数据源清单

更新日期：2026-05-22

这个文件记录真实心理学/精神病学对话数据中需要注册、申请或联系作者的数据源。不要尝试绕过访问限制；只记录申请入口、访问条件和对 Deviation Bench 的可能用途。

## 高优先级

### PsychosisBank DISCOURSE-UWO

- URL：`https://talkbank.org/psychosis/access/English/Palaniyappan/Discourse-UWO.html`
- 所属平台：PsychosisBank / TalkBank。
- 数据类型：早期精神病相关自然互动语音和转录，含临床、认知、人口学变量。
- 访问状态：需 PsychosisBank / DISCOURSE consortium 审批；非商业研究用途。
- 对本项目价值：
  - 高。真实 psychosis discourse，且有临床变量，可作为 UIRD 场景设计和标注维度的重要参照。
- 下一步：
  - 准备研究用途说明。
  - 申请 PsychosisBank membership / 数据访问。

### PsychosisBank Tang Corpus

- URL：`https://talkbank.org/psychosis/access/English/Tang.html`
- 所属平台：PsychosisBank / TalkBank。
- 数据类型：psychosis discourse / conversations。
- 访问状态：PsychosisBank 访问规则，可能需要 membership。
- 对本项目价值：
  - 高。真实 psychosis conversation，可补充 DAIS-C 的访谈语料。
- 下一步：
  - 检查是否可浏览 transcript。
  - 申请下载权限。

### AVATAR Therapy Dialogue Corpus

- URL：`https://kcl.figshare.com/articles/dataset/AVATAR_Therapy_Dialogue_Corpus/28334615`
- 数据类型：与 voice-hearing / psychosis therapy dialogue 相关。
- 访问状态：记录存在，但具体下载权限需进一步确认。
- 对本项目价值：
  - 中到高。若可获取真实治疗对话，可用于理解 voice / belief reinforcement 场景。
- 下一步：
  - 检查 Figshare 文件是否开放。
  - 若不可下载，联系作者或机构申请。

### PDCH Full Dataset

- DOI：`10.57760/sciencedb.27818`
- ScienceDB URL：`https://www.scidb.cn/detail?dataSetId=9dab4a81cc8746108c44fbdecd7b579b`
- 相关 GitHub：`https://github.com/Miraclemarvel55/PDCH`
- 数据类型：心理健康/抑郁相关对话、评分、音频/文本和标注结构；具体字段需以正式申请后下载包为准。
- 访问状态：ScienceDB 页面当前显示 RESTRICTED。GitHub 只公开 README、代码和小型 metadata，完整数据未直接下载。
- 本地状态：
  - 已保存公开 metadata / code snapshot：`deviation-bench/data_sources/downloaded/pdch_metadata/`
  - 未获得 full dataset。
- 对本项目价值：
  - 中到高。可参考 HAMD、emotion、dialogue annotation 的结构；但主题不是 delusion / psychosis 主线。
- 下一步：
  - 准备研究说明，申请 ScienceDB restricted access。
  - 申请前明确只用于抽象 conversation pattern / annotation schema，不公开原始受访者内容。

## 中优先级

### DAIC-WOZ

- URL：`https://dcapswoz.ict.usc.edu/`
- 数据类型：人机访谈，包含转录、音视频和心理困扰相关变量。
- 访问状态：需申请；要求学术邮箱。
- 对本项目价值：
  - 中。它不是 delusion / psychosis 专门数据，但适合参考临床访谈结构和多轮问答格式。
- 下一步：
  - 如需要 general clinical interview baseline，再申请。

### MODMA

- URL：`https://modma.lzu.edu.cn/data/index/`
- 数据类型：抑郁相关多模态数据，包含语音/访谈类材料；不是 delusion / psychosis 专门数据。
- 访问状态：通常需要同意使用条款或提交申请；体量较大。
- 对本项目价值：
  - 中。可作为 general clinical interview / speech baseline 参考，但对 UIRD 的直接价值低于 psychosis dialogue。
- 下一步：
  - 只在需要 multimodal / depression control 时申请或下载。
  - 若下载，避免把大音频包直接放进普通 Git；优先使用外部存储或 Git LFS。

### D4 Chinese Mental Health Dialogue Dataset

- URL：待复核具体官方入口。
- 数据类型：中文心理健康/咨询对话数据。
- 访问状态：可能需要 DUA 或申请。
- 对本项目价值：
  - 中。若能获取，可作为中文对话格式和安全回应参照。
- 下一步：
  - 查找官方论文/主页和下载条款。
  - 明确是否允许再分发后再纳入仓库。

### HOPE / MEMO Therapy Dialogue Datasets

- URL：待复核具体官方入口。
- 数据类型：心理咨询/治疗对话数据。
- 访问状态：多为联系作者或机构申请。
- 对本项目价值：
  - 中。可作为治疗对话中的 grounding / reflection / validation style 参照。
- 下一步：
  - 找到官方数据页、论文、联系人和许可说明。

### Psych8k

- URL：`https://huggingface.co/datasets` 上的 Psych8k 相关条目，具体 dataset id 后续复核。
- 数据类型：mental health / psychological counseling 数据；未确认为真实临床对话。
- 访问状态：Hugging Face gated / 需申请。
- 对本项目价值：
  - 低到中。可作为 mental-health safety / counseling response 参照，但不是 delusion 主数据。
- 下一步：
  - 申请前先确认 license、数据来源、是否可再分发。

## 低优先级 / 背景参考

### SMHD and related social-media mental-health datasets

- URL：`https://ir.cs.georgetown.edu/resources/smhd.html`
- 数据类型：社交媒体文本，不是临床对话。
- 访问状态：通常需要遵守平台和数据集规则。
- 对本项目价值：
  - 低。不是用户需要的真实对话数据，也不是 delusion-specific。
- 下一步：
  - 仅作为背景或文本分类参考，不作为 v1 主数据。

### TalkBank Control Corpora

- 例子：
  - DementiaBank
  - AphasiaBank
  - FluencyBank
- URL：`https://talkbank.org/`
- 数据类型：受控访问的语言/认知/临床交流语料。
- 访问状态：需要 TalkBank membership / 数据协议。
- 对本项目价值：
  - 低到中。主要用于 discourse control，不是 UIRD 或 delusion 主数据。
- 下一步：
  - 只在需要非 psychosis 临床语言对照组时申请。

## 申请说明模板

申请时应强调：

- 研究目的：构建 LLM context-retest / reality-grounding drift benchmark。
- 数据用途：只用于抽象语言模式、标注维度设计和 aggregate analysis。
- 不做事项：
  - 不训练临床诊断模型。
  - 不公开再分发受限原始数据。
  - 不把可识别或敏感原文放入公开 benchmark。
  - 不构建诱导真实用户心理恶化的系统。
