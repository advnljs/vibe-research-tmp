# Deviation Bench 后续优先级路线图

更新日期：2026-06-04

本文按 benchmark paper 的五个关键支柱排序：Evaluation validity 优先于数据扩展，Construction pipeline 优先于规模化实验，Empirical findings 必须建立在稳定自动评测之上。

当前约束：

- 主路线升级：用 Deviation Bench 评测 agent memory 系统，比较 full transcript 与 memory systems 在 reality-boundary 场景中的可靠性。
- 原主路线 Framing A 仍作为底座：real-corpus-anchored context-retest reliability benchmark 提供 evidence anchors、fictional naturalistic episodes、judge/metajudge 和安全边界。
- 当前论文 hook：**agent memory can be delusive**，即 memory layer 可能把反复出现的 unsupported claim 写入持久上下文，并被后续 LLM generation 当作事实接受。
- 论文不使用人类标注。
- 评测证据必须走 LLM-only route：primary judge + metajudge / second judge + judge variance + gold-control + schema/rule checks。
- `uird_pilot_001` 是 development calibration item。
- `uird_pilot_002` / `uird_pilot_003` 是 used held-out smoke items，不再算 fresh unseen evidence。

状态：已完成第一版 protocol。

- 当前 agent memory 系统多为广义 RAG / retrieval / graph / summary 路线，可能丢失信息并放大妄想式 unsupported claim。
- 目标系统可从 mem0、Graphiti 等开始，但需先做 tooling survey。

## Priority M1: 候选 memory 系统 tooling survey

状态：已完成第一版 survey。

原因：mem0、Graphiti 等系统版本变化快，不能只凭泛化印象写论文 claim。正式 survey 必须把“系统实际做什么”和“本实验如何公平复现”写清楚。

建议产物：

- `deviation-bench/agent_memory_system_survey.md`

最小内容：

- mem0：
  - SDK/API、版本、license；
  - local/self-hosted/cloud 路线；
  - write/add 行为、LLM extraction、embedding/vector store、retrieval top-k；
  - 是否支持 update/delete、metadata、verification flag、provenance。
- Graphiti：
  - SDK/API、版本、license；
  - graph backend 需求；
  - episode ingestion、entity/relation extraction、temporal validity、provenance；
  - hybrid search recipe 和检索结果如何注入 target context。
- 可选候选：Zep、LangGraph memory、LlamaIndex memory、MemGPT / Letta、LongMemEval / LoCoMo 常见 baselines。
- 对每个系统给出：
  - 是否进入主实验；
  - 作为 external baseline 还是 appendix；
  - 最小可复现配置；
  - 与本地 simulator 条件的对应关系。

完成标准：

- 论文不再写“现有 agent memory 都是某种路线”的泛化断言，只写 tested configurations。
- runner 实现前已经知道每个 external baseline 的写入、检索和 trace 可观测性。

完成结果：

- `deviation-bench/agent_memory_system_survey.md` 已创建。
- 第一批外部主 baseline 建议为：
  - mem0 OSS：fact-memory / hybrid retrieval baseline。
  - Graphiti OSS：temporal graph / provenance baseline。
- Zep、LangGraph Store、LlamaIndex Memory、Letta 暂定位为 appendix / future / implementation reference。
- 已记录当前环境约束：默认 `python3` 是 3.8.10，且无 `pip`；外部 mem0 / Graphiti smoke 前需要 Python 3.10+ venv / 容器 / 替代环境。

## Priority 2: 创建 gold-control scenarios

状态：已完成第一版。

原因：没有人类标注后，必须用程序化 obvious cases 校准 judge 是否能识别显然样本。

建议产物：

- `deviation-bench/prompts/gold_control_scenarios.yaml`
- 或先集成到 `pilot_scenarios.yaml` 中单独标记 `is_gold_control: true`。

最小覆盖：

| Control | 目标 |
|---|---|
| neutral paraphrase no-drift | 检查普通改写不被误标为 drift |
| explicit no-evidence | 检查 evidence-bound refusal |
| positive endorsement | 检查直接支持 unsupported claim 时能标 factual error |
| confabulation | 检查编造动机/机制时能标 elaboration |
| recovery success | 检查回到 evidence boundary 时能标 recovery success |
| recovery failure | 检查继续支持 claim 时能标 failure |
| safety taxonomy | 检查只有固定安全类别进入 `safety_flags` |

完成标准：

- scenario validation 通过。
- mock / small real judge run 可得到 gold-control pass rate。
- `LLM-only评测与验证方案.md` 中的 reliability metrics 有可计算输入。

完成结果：

- `deviation-bench/prompts/gold_control_scenarios.yaml` 已创建。
- 第一版包含 11 条 synthetic turn-level controls：
  - grounded negative
  - empathy without external endorsement
  - minor transcript slip not factual error
  - positive endorsement
  - confabulatory elaboration
  - unjustified reversal
  - recovery success
  - recovery failure
  - real-person-targeting safety taxonomy
  - privacy-intrusion safety taxonomy
  - non-safety drift label boundary
- YAML parse 和本地规则校验已通过：唯一 ID、stance-score 匹配、drift_event 匹配、recovery_success 轮次规则、safety taxonomy、无 target-visible marker 泄漏。

## Priority 4: 生成 1-2 个 Tier 2 real-to-dialogue 草稿

原因：用户希望更贴近真实数据，但不能复制真实文本；Tier 2 是生态效度和伦理边界之间的折中。

建议输入：

- `data_sources/patterns/seed_pattern_bank.jsonl`
- 或 DAIS-C / first-episode friendship 的去标识化短摘要。

建议命令形态：

```bash
python3 deviation-bench/src/rewrite_real_to_dialogue.py \
  --input <jsonl> \
  --provider openai \
  --model deepseek-v4-pro \
  --base-url https://api.deepseek.com \
  --limit 2
```

自动 QC：

- no copied source phrases。
- no identifiable person/place/institution/event chain。
- exactly 30 target-facing turns。
- all induction turns add no evidence。
- no target-visible benchmark/test/judge/rubric wording。
- metajudge / scenario QC 通过。

完成标准：

- 1-2 个草稿通过自动 QC。
- 通过后再手动移入 `pilot_scenarios.yaml`，保留 `source_inspiration`、`realism_profile`、`copied_text=false`。
